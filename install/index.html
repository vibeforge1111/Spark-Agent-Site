Guided first install

Install Spark without guessing.

Copy one command. Spark shows the plan first. Then connect Telegram and your model. Spark Live, memory, and missions come next.

Copy install command See what it changes

What you need ready

  • Telegram app and access to @BotFather
  • One LLM path: Codex CLI, Claude Code, OpenRouter, Z.AI, MiniMax, Hugging Face, LM Studio, or Ollama
  • A terminal: PowerShell on Windows, Terminal on Mac/Linux/WSL
Step 1

Choose where you are installing.

If you are using Claude, Codex, or another coding agent, give it the agent prompt. If you are installing yourself, use the command for your computer.

Agent prompt Best for Claude, Codex, Cursor, or any agent terminal 
Install Spark from https://agent.sparkswarm.ai/install. Review the installer plan with me, then finish Telegram BotFather and LLM provider setup.
Mac / Linux / WSL Paste into Terminal 
curl -fsSL https://agent.sparkswarm.ai/install.sh -o spark-install.sh && bash spark-install.sh
Windows Paste into PowerShell 
iwr https://agent.sparkswarm.ai/install.ps1 -OutFile spark-install.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File .\spark-install.ps1
Step 2

Follow the first-run questions.

1

Create the Telegram bot

Open Telegram, message @BotFather, create a bot, and paste the token only into local Spark setup. Never paste it into the website.

2

Choose one LLM provider first

Use one provider for agent chat, memory, and missions. You can split agent and mission models later from spark setup.

3

Start Spark Live

Spark Live starts the background services without opening extra terminal windows. Use spark live start and check with spark live status.

4

Test the bot

In Telegram, send /diagnose, then /remember I like concise warm replies, then /run say exactly OK.

Already installed?

Update Spark.

If Spark is already on your computer, start with the normal update command. It keeps your existing setup, pulls the latest modules, and avoids making you reinstall from scratch.

Normal update spark update

Use this when Spark already works and you just want the newest fixes.

After updating spark verify --onboarding

Checks Telegram, providers, memory, Spark Live, and missions.

Installer fallback for very old Spark installs

Use this only when your local Spark does not know spark update or another command from the docs.

Mac / Linux / WSL bash spark-install.sh --upgrade-existing
Windows powershell -NoProfile -ExecutionPolicy Bypass -File .\spark-install.ps1 -UpgradeExisting

Want to preview first? Add --dry-run on Mac/Linux/WSL or -DryRun on Windows.
