Spark Suites

The starter kit in normal words.

The default suite is telegram-starter. It gives Spark a chat door, a brain router, memory, Mission Control, and research loops.

Agent Markdown commands.json Self-improvement

How the pieces talk.

Telegram Builder LLM Memory Missions

Telegram is where the user talks. Builder routes the work. The LLM thinks. Memory remembers. Mission Control handles bigger tasks.

The modules.

Front Door

Telegram Bot

Receives commands and normal messages. Uses long polling, not webhooks.

Brain Router

Intelligence Builder

Routes chat, memory, builder, and mission roles to the chosen providers.

Memory

Domain Chip Memory

Saves and recalls useful facts when memory is wired and enabled.

Missions

Spawner UI

Mission Control for bigger work, boards, and tracked execution.

Research

Spark Researcher

Runs evidence, advisory, and bounded improvement workflows.

Identity

Spark Character

Keeps role, voice, and access-level behavior stable.

Startup

Spark Live

Runs Spark services quietly in the background and can autostart after login.

What users should try first.

1

Prove chat

Send /start, /myid, and a normal message in Telegram.

2

Prove memory

Send /remember launch test memory, then /recall launch test memory.

3

Prove missions

Send /run summarize the current Spark setup, then /board.
