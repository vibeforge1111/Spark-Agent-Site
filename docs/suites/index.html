How the pieces talk.

Telegram Runtime LLM Memory Missions

Telegram is where the user talks. Spark Intelligence Builder routes the work. The LLM thinks. Memory remembers. Mission Control handles bigger tasks.

The modules.

Front Door

Spark Telegram Bot

Receives commands and normal messages.

Uses long polling, not webhooks.

Runtime Router

Spark Intelligence Builder

Routes Agent and Mission roles.

Connects providers, memory, and tools.

Memory

Domain Chip Memory

Saves useful facts when memory is wired.

Recalls context when Spark needs it.

Missions

Spawner UI

Mission Control for bigger work.

Shows boards and tracked execution.

Research

Spark Researcher

Runs evidence and advisory workflows.

Supports bounded improvement loops.

Identity

Spark Character

Keeps role and voice stable.

Tracks access-level behavior.

Startup

Spark Live

Runs Spark services quietly.

Can autostart after login.

What users should try first.

1

Prove chat

Send /start, /myid, and a normal message in Telegram.

2

Prove memory

Send /remember launch test memory, then /recall launch test memory.

3

Prove missions

Send /run summarize the current Spark setup, then /board.
