Commands

The small command map for daily Spark use.

Use Spark Live for running services, providers for model checks, verify for proof, and fix when one layer is stuck.

Agent Markdown Providers Troubleshooting

First day commands.

Setup

spark setup
spark guide
spark recommend llms

spark setup asks for Telegram, one default LLM provider, and access level defaults. Start simple; customize later.

Turn Spark on

spark live start
spark live status
spark autostart install --now

spark live is the normal way to run Spark services without opening extra terminal windows.

Prove it works

spark providers status
spark providers test --role chat
spark verify --onboarding

These commands prove the model, Telegram, memory, Mission Control, and runtime are connected.

Fix the common things

spark fix telegram
spark fix spawner
spark logs spark-telegram-bot --lines 80
spark logs spawner-ui --lines 80

Use this when the bot is quiet or Mission Control is unreachable.

Telegram commands.

/start

Shows the basic Telegram command surface.

/myid

Shows your Telegram ID for admin setup.

/diagnose

Checks Telegram, provider routing, memory, and Spawner health.

/remember <note>

Saves useful facts through Spark memory.

/recall <topic>

Searches saved memory.

/run <goal>

Starts a build or research mission through Spawner.

/board

Shows running and completed missions.

/access 3

Sets the recommended Research + Build access level. Use /access 1 through /access 4 to change it.

Admin and support commands.

Health and proof

spark status
spark verify --deep
spark verify --provenance
spark verify --installers --hosted-installers

Provider control

spark providers list
spark providers status
spark providers test --role chat
spark setup --llm-provider codex

Security and support

spark security audit
spark doctor llm "Telegram bot is quiet"
spark support bundle

Doctor and support flows redact secrets. Include logs only when you opt in.

Lifecycle

spark update
spark restart telegram-starter
spark live stop
