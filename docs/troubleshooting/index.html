Troubleshooting

Fix the smallest broken layer first.

Do not guess. Check Spark Live, then providers, then Telegram, then memory, then Spawner. Each command should make the next step obvious.

Agent Markdown Commands Security

First five checks.

spark live status
spark status
spark providers status
spark providers test --role chat
spark verify --onboarding

If a Telegram error says a local service is unreachable, run /diagnose in Telegram or spark fix spawner locally.

Symptom to fix map.

Bot is quiet

Run spark fix telegram. Then check spark logs spark-telegram-bot --lines 80.

Bot says private or admin only

Send /myid, add that ID in spark setup, then restart Spark Live.

LLM replies fail

Run spark providers test --role chat. Rerun setup if the selected provider is missing or pointing to the wrong endpoint.

Memory does not stick

Run spark verify --deep. Then test /remember and /recall with a unique phrase.

Spawner is unreachable

Run spark fix spawner, then spark live status. The user-friendly error is "Mission Control is offline."

Update failed

Run spark security audit and spark logs. If a trust scan blocks a test fixture, update Spark before bypassing anything.

When to use LLM Doctor.

Use the LLM doctor after the basic checks show a real problem and the normal fix command did not solve it.

spark doctor llm "Telegram bot is quiet after restart" --save-report
spark doctor llm "Spawner says ECONNREFUSED on 5173" --include-logs --save-report

Privacy rule

Doctor redacts secrets before sending context to the user's configured LLM. Logs are excluded unless the user opts in.
