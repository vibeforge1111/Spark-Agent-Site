What high-signal feedback looks like.

Clear

Point at the exact surface.

Name the page, command, module, or repo. Add the URL or command you used.

Safe

Redact secrets first.

Never include API keys, Telegram tokens, private memory, private repos, or raw logs that expose a user.

Useful

Suggest the smallest improvement.

A good issue says what would have helped: one sentence, one command, one screenshot, one check, or one test.

Open source appreciation

Useful issues, redacted reproductions, and PRs make Spark easier for everyone. When practical, we will acknowledge helpful contributors in issues, release notes, or docs updates.
