Symptom map.

No Telegram reply

Run spark fix telegram, then spark logs spark-telegram-bot.

Check token, admin ID, and duplicate polling.

Only memory labels

Run spark providers status and spark verify --deep.

The LLM role or memory bridge may not be wired.

Memory missing

Send /remember and /recall. Then run spark verify --deep.

Missions missing

Send /run, then /board. If nothing appears, run spark fix spawner.
