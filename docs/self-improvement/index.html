Self-Improvement

Make Spark better by giving it a score.

A domain chip tells Spark what good means. A benchmark keeps it honest. A loop tries small changes and records what happened.

Agent Markdown Suites Agent context

The loop.

Task Score Ledger Memory Next try

This is recursive, but bounded. Spark should not get unlimited permission. It should run a small trial, score it, explain it, and wait for review when changes are risky.

What each part means.

Domain Chip

The specialist brain

Owns domain scoring, suggestions, packets, and watchtower pages.

Benchmark

The truth meter

Scores real outcomes so the agent cannot confuse more words with more progress.

Ledger

The paper trail

Records what was tried, what changed, and what happened.

Memory

The lesson shelf

Saves only useful patterns, boundaries, evidence, and frontier ideas.
