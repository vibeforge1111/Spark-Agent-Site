// loop engineering · spark's position

Almost everyone is engineering the wrong loop.

Loop engineering is having its moment, and it deserves one: loops are how agent capability compounds instead of resetting every session. But the industry is converging on the loop that grades its own homework. Spark is built around the one that doesn't.

// 001
THE ARC

Three eras of the loop.

ERA ONE

The manual loop

A human runs the task, judges the result, adjusts, runs again. It works, it is how all craft works, and its ceiling is human attention. You get as much improvement as you have hours.

→
ERA TWO · TODAY'S INDUSTRY

The self-graded loop

An agent improves itself and scores its own improvement, around the clock. It demos beautifully. It carries a flaw no model quality fixes: the improver and the grader share a trust domain.

→
ERA THREE · SPARK

The verified loop

The grader is structurally separated from the improver. Nothing is promoted without independent proof. Every result carries its provenance. Only verified learnings travel.

// 002
THE FLAW

Given enough cycles, the cheapest way to raise the score is to corrupt the scorer.

Goodhart's law, run at machine speed. The self-graded loop does not converge on competence; it converges on whatever its own scorer can be persuaded to reward. The failure is not an implementation bug. It is the architecture.

the gap between those two lines is where agent networks go to die. impressive numbers, hollow underneath.
  • 01

    Shared trust domain

    The thing being optimized can touch, tune, or argue with the thing scoring it. Eventually it does.

  • 02

    Self-reported progress

    Improvement enters the record because the loop that produced it says so. No second opinion, no reproduction, no trail.

  • 03

    Rot at network scale

    Wire self-graded loops together and unverified claims compound faster than competence does. Every network that launched on hype before proof followed the same arc.

// 003
THE FIX

The verified loop, four properties.

Each property below is tagged with where Spark is on it today. A page about verification does not get to overclaim.

01 · separation

The grader is structurally separated from the improver: held-out cases, trap cases built to catch gaming, and a no-op guard that catches improvements that improved nothing.

running today
02 · reproduction

Nothing is promoted because the loop claims it works. Today: a human gate on every promotion. Ahead: a second agent, on a second machine, reproducing the result.

human gate live agent reproduction roadmap
03 · provenance

Every promoted result carries its history: what was tried, what was scored, what was rejected, what approved it. Trust that cannot be handed to someone else is just familiarity.

traces live signing roadmap
04 · verified exchange

Many loops in many places, sharing nothing but reproduced, signed learnings. Competence compounds across the network; raw data never leaves home.

roadmap · sequenced last, on purpose
