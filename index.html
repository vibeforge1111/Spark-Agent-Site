009 · install

One safe path. The whole Spark stack.

Use this page as the copy-paste path for a terminal, Codex Cloud, WSL, or any agent harness. The installer brings the starter ecosystem together: Researcher, Builder, Memory, Spawner UI, and Telegram bot.

spark-researcher spark-intelligence-builder domain-chip-memory spawner-ui spark-telegram-bot
WSL / Linux / macOS Download, inspect, run
curl -fsSLO https://agent.sparkswarm.ai/install.sh less install.sh bash ./install.sh
Windows PowerShell Download, inspect, run
iwr https://agent.sparkswarm.ai/install.ps1 -OutFile .\install.ps1 Get-Content .\install.ps1 powershell -ExecutionPolicy Bypass -File .\install.ps1
01

Install the CLI

The script installs Spark CLI, checks Python and Node, and prepares an isolated Spark home instead of scattering files across your machine.

02

Run setup

spark setup defaults to the starter bundle and asks for Telegram and LLM provider configuration in one wizard.

03

Verify the agent

Run spark status, start Telegram long polling, then send /start, /myid, and a normal message to the bot.

check spark status
bot spark start spark-telegram-bot
ui spark start spawner-ui
secure by default

No webhook exposure in the launch path. Telegram runs by long polling, and generated relay secrets are stored in Spark configuration instead of being printed into docs.

bring your LLM

Setup asks for your provider and key. Spark can use GLM/z.ai or another OpenAI-compatible endpoint without hardcoding secrets into the repo.

agent friendly

Give this page to Codex, a cloud terminal, or another harness. It has the exact modules, commands, and verification checks needed to finish onboarding.
